# 🎵 节奏大挑战 · Rhythm Challenge

一个单文件 HTML 网页应用，可以做课堂单词节奏训练。

## ✨ 功能

- 8 格子输入 - 文字 / Emoji / 图片三种内容类型
- 可调节奏 - 快速 (120 BPM) / 慢速 (50 BPM)
- 倒计时 3-2-1-GO 开始
- BGM 系统 - 内置鼓点节奏 或 上传自定义音频
- Tempo 滑块 - 50%-200% 变速播放
- 回合系统 - 可设回合数 + 每回合加速
- 答题反馈 - 学生在高亮时点击格子记分
- 分享链接 - 一键生成含全部配置的 URL
- 批量导入 - 一行一个单词
- JSON 配置导出/导入

## ⌨️ 快捷键

- Space 开始/暂停
- ← → 切换格子
- R 重置
- S 设置
- F 全屏
- M 静音
- 1-8 答题

## 🎓 课堂用法

1. 老师投影此网页
2. 编辑模式输入本课 8 个单词
3. 切到开始挑战
4. 选快速/慢速，点 ▶ 开始
5. 学生跟着红色高亮的格子说单词
